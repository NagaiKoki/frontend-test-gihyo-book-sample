---
name: debug-test
description: テストの失敗原因を調査して修正する
argument-hint: "[エラーメッセージまたはテストファイルのパス]"
---

テストが失敗しています。原因を調査して修正してください。

$ARGUMENTS に記載されている情報（またはターミナルの出力）をもとに、
以下の順序で調査してください。

1. エラーメッセージから失敗の原因を特定する
2. テストコードのロジックに問題がないか確認する
3. 実装コードに対してテストの期待値が正しいか確認する
4. モックの設定が実際の挙動と一致しているか確認する

修正が必要な場合は修正を行い、テストを再実行して通ることを確認してください。
